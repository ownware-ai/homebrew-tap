# Easelry Homebrew tap

```sh
brew install ownware-ai/tap/easelry
easelry
```

Easelry: your agents work on your real Word, Excel and PowerPoint files. You see every change, and can undo any of it.
Works with Claude Code, Codex and Claude Desktop. Nothing leaves your Mac.

The plugin that teaches an agent how to work in Easelry: https://github.com/ownware-ai/easelry-plugin
